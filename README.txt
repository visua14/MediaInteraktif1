MEDIA INTERAKTIF: Persahabatan di Hutan Rimba

Membuka di VS Code:
1. Ekstrak ZIP, lalu File > Open Folder > media-fabel.
2. Klik kanan index.html > "Open with Live Server", atau buka index.html langsung di browser.

Mencoba di Android / iOS:
- Dengan Live Server, buka alamat jaringan (mis. http://192.168.x.x:5500) dari HP yang terhubung ke Wi-Fi yang sama.
- Di Chrome Android: menu ⋮ > "Tambahkan ke layar utama". Di Safari iOS: Bagikan > "Tambah ke Layar Utama" agar tampil layar penuh.

File: index.html (struktur & latar SVG), style.css (tampilan), script.js (navigasi, slide, kuis).
Soal kuis diubah pada array "bank" di script.js.
Font memakai Google Fonts (perlu internet); tanpa internet dipakai font cadangan.
